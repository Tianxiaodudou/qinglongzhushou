# 青龙助手

青龙面板 Android 客户端，使用 Jetpack Compose + Kotlin + Clean Architecture 构建，提供完整的青龙面板移动端管理体验。

---

## 📱 功能总览

青龙助手覆盖青龙面板的全部核心管理功能，通过左侧抽屉导航栏快速切换各模块。

## 🔐 登录与服务器管理

<img src="docs/screenshots/login.jpg" width="280" alt="登录界面"/>

### 登录功能
- **HTTP / HTTPS** 协议切换：支持直连青龙面板（HTTP）或通过反向代理（HTTPS）连接
- **域名 + 端口** 分开输入，灵活适配不同部署方式
- **用户名 + 密码** 认证，Token 自动保存至 EncryptedSharedPreferences（加密存储）
- **两步验证（2FA）**：面板开启 2FA 时自动检测并弹出验证码输入框，支持 6 位数字验证码
- **自动登录**：下次启动时自动用保存的 Token 或账号密码尝试登录，无需重复输入

### 服务器管理
- **多服务器**：支持保存多个青龙面板服务器配置
- **新增 / 编辑 / 删除**：可自由管理已保存的服务器
- **快速切换**：左侧抽屉栏点击「切换服务器」即可切换并自动登录
- **命名**：每个服务器可自定义显示名称，方便区分不同面板

## 📋 定时任务

<img src="docs/screenshots/tasks.jpg" width="280" alt="定时任务界面"/>

### 任务列表
- 分页卡片展示所有定时任务，支持自定义每页卡片数（10~100）
- 显示任务名称、状态、最后执行时间、下次运行时间、标签等信息
- 标签筛选：支持按「全部」「运行中」「已禁用」等视图标签快速过滤
- **自定义视图**：支持创建 / 编辑 / 删除自定义视图标签，按多条件组合过滤

### 搜索
- **按名称搜索**：模糊匹配任务名称
- **按订阅搜索**：根据所属订阅筛选
- **按标签搜索**：根据任务标签筛选
- 搜索模式可在搜索框左侧切换

### 批量操作
- 长按任务卡片进入批量选择模式
- 支持批量：运行、停止、启用、禁用、删除

### 任务管理
- **新建任务**：设置名称、命令、定时规则、标签、日志名称等
- **编辑任务**：修改已存在的任务配置
- **删除任务**：支持单个删除
- **运行 / 停止**：立即执行或停止任务

### 日志查看
- 点击任务卡片查看实时日志（自动轮询刷新）
- 浏览历史日志文件列表，支持多选删除
- 自定义日志刷新间隔（1000ms ~ 60000ms）

## 📦 订阅管理

### 订阅列表

- 支持搜索过滤

### 订阅 CRUD

- **编辑订阅**：修改已有订阅配置
- **删除订阅**：单个或批量删除

### 批量操作
- 批量启用 / 禁用
- 批量运行
- 批量停止

## 🌿 环境变量

### 变量列表
- 列表展示所有环境变量，显示名称、值、备注等
- 支持搜索过滤
- 自定义每页显示数量

### 变量管理
- **新增**：添加新的环境变量（名称、值、备注、标签等）

### 批量操作
- 批量启用 / 禁用

## 📄 脚本管理

- 树形文件浏览，查看青龙面板上的脚本文件目录

## 🛠️ 面板设置

- 提供简洁的移动端操作界面

## 📢 通知设置

<img src="docs/screenshots/notification.jpg" width="280" alt="通知设置界面"/>

支持 22 种通知方式的一键配置：

- **企业微信**：企业微信机器人 Webhook 通知
- **Server 酱**：Server 酱 / Server 酱 Turbo
- **PushDeer**：PushDeer 自定义推送
- **Bark**：iOS Bark 推送
- **Telegram**：Telegram Bot 通知
- **钉钉**：钉钉机器人 Webhook
- **飞书**：飞书机器人 Webhook
- **SMTP 邮件**：通过 SMTP 发送邮件通知
- **iGot**：iGot 聚合推送
- **GoCQhttp**：QQ 机器人通知
- **PushPlus**：PushPlus 推送
- **WeWork APP**：企业微信应用消息
- **自定义 Webhook**：自定义 URL 回调通知
- … 其他多种通知方式

每种通知方式都有对应的配置表单，填写对应密钥/URL 即可启用。

## 🛠️ 技术栈

| 技术 | 说明 |
|------|------|
| **UI** | Jetpack Compose + Material Design 3 |
| **架构** | Clean Architecture + MVVM |
| **DI** | Hilt (Dagger) |
| **网络** | Retrofit + OkHttp + Gson |
| **异步** | Kotlin Coroutines + Flow |
| **导航** | Navigation Compose |
| **图片** | Coil |
| **本地存储** | EncryptedSharedPreferences + DataStore |
| **安全** | Security Crypto |
| **最低 SDK** | Android 14 (API 34) |
| **目标 SDK** | Android 15 (API 35) |
| **语言** | Kotlin |

## 🔒 隐私与安全

- 所有认证信息（Token、密码）均使用 **Android EncryptedSharedPreferences** 加密存储
- 网络请求自动注入 Bearer Token（JWT）认证头
- 支持两步验证（2FA），保障账户安全
- 密码输入支持明文/密文切换
