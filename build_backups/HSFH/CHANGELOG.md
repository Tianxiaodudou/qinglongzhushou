# HSFH 版本变更日志

## 变更内容

### 新增
- **通知设置页面**：从青龙面板源代码解析后，将通知设置功能集成到 APP 导航栏
  - 支持 22 种通知方式（Gotify、Ntfy、Server酱、PushDeer、Bark、Telegram机器人、钉钉机器人、企业微信机器人/应用、邮箱、飞书机器人、PushPlus、IGot、wxPusher、自定义通知、群晖Chat、PushMe、GoCqHttpBot、智能微秘书、微加机器人、Chronocat、OpeniLink）
  - 每种通知方式显示对应的配置字段和提示说明
  - 保存时青龙面板自动发送测试通知验证配置
  - 支持已关闭通知状态
  - 完整的加载/保存/错误处理状态
  - 抽屉菜单新增「通知设置」入口，"面板设置"改为"系统设置"
