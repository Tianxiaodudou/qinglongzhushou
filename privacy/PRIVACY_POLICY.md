# 隐私政策

**最后更新日期：2026年5月23日**

## 简介

青龙助手（QingLong Assistant）是一款开源 Android 客户端应用，用于管理青龙面板（QingLong Panel）的定时任务。本隐私政策说明了我们如何收集、使用和保护您的信息。

## 信息收集

### 我们收集的信息

本应用**不会**收集任何个人信息。应用完全在本地运行，所有数据仅存储在您的设备上。

#### 您主动提供的信息
- **服务器地址**：您输入的青龙面板服务器地址（IP/域名、端口）
- **登录凭证**：您输入的用户名和密码，仅用于登录青龙面板
- **认证令牌**：登录成功后生成的 Token，用于后续 API 请求

以上信息仅存储在您设备的本地存储中，**不会**上传到任何第三方服务器。

### 我们不收集的信息
- 不收集位置信息
- 不收集设备标识符（IMEI、MAC 地址等）
- 不收集通讯录、短信、通话记录
- 不收集照片、媒体文件
- 不收集浏览记录
- 不收集个人身份信息（姓名、身份证号、银行卡号等）

## 权限说明

本应用申请的权限及其用途：

| 权限 | 用途 | 说明 |
|------|------|------|
| `INTERNET` | 网络通信 | 与青龙面板服务器通信，管理定时任务 |
| `ACCESS_NETWORK_STATE` | 网络状态检测 | 检查网络连接状态 |
| `POST_NOTIFICATIONS` | 通知推送 | 任务执行结果通知（Android 13+） |
| `WRITE_EXTERNAL_STORAGE` | 存储日志 | 将运行日志写入 Download 目录（仅 Android 9 及以下需要） |

**Android 10+**：通过 MediaStore API 写入日志文件，无需存储权限。

## 数据存储与安全

- **本地存储**：所有数据（服务器地址、登录凭证、认证令牌）仅存储在您设备的本地存储中
- **加密存储**：敏感信息（如密码）使用 Android 加密存储（EncryptedSharedPreferences）保存
- **网络传输**：与青龙面板的通信使用 HTTP/HTTPS 协议，您可以选择使用 HTTPS 加密传输
- **日志文件**：运行日志写入 `Download/qinglong.txt`，每次启动覆盖，不包含密码等敏感信息

## 数据共享

本应用**不会**与任何第三方共享您的数据。应用完全离线运行，所有操作仅在您的设备和青龙面板服务器之间进行。

- **Jetpack Compose**：UI 框架
- **Hilt**：依赖注入框架
- **Gson**：JSON 解析库
