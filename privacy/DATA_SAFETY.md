# 数据安全声明

**应用名称：青龙助手（QingLong Assistant）**
**包名：com.qinglong.app**
**版本：1.0.0**

## 数据收集与使用

本应用**不收集任何用户数据**。所有操作均在本地设备和用户指定的青龙面板服务器之间进行。

### 数据类型

| 数据类型 | 是否收集 | 用途 | 是否共享给第三方 |
|---------|---------|------|----------------|
| 服务器地址 | 是（本地存储） | 连接青龙面板 | 否 |
| 用户名 | 是（本地存储） | 登录青龙面板 | 否 |
| 密码 | 是（本地加密存储） | 登录青龙面板 | 否 |
| 认证令牌 | 是（本地存储） | API 认证 | 否 |
| 运行日志 | 是（本地文件） | 问题排查 | 否 |
| 设备标识符 | 否 | - | - |
| 位置信息 | 否 | - | - |
| 个人身份信息 | 否 | - | - |

### 数据加密

- 密码使用 Android EncryptedSharedPreferences 加密存储
- 网络传输支持 HTTPS 加密

### 数据删除

- 卸载应用即可删除所有本地数据
- 日志文件位于 `Download/qinglong.txt`，可手动删除

## 数据安全措施

1. 所有数据仅存储在用户设备本地
2. 敏感信息使用平台级加密存储
3. 不向任何第三方传输用户数据
4. 代码完全开源，接受社区审查

## 合规声明

本应用符合 Google Play 的数据安全要求，属于"不收集数据"类别。
